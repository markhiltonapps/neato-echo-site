Email **[hello@neatoventures.com](mailto:hello@neatoventures.com)**. A real person
reads every message.

## What to include

Most of the back-and-forth in a support thread is us asking for three things.
Send them up front and we can usually answer on the first reply:

<Steps>
  <Step title="Your Windows version">
    Windows 10 or Windows 11, and which build if you know it (**Settings → System → About**).
  </Step>

  <Step title="Your Neato Echo version">
    Open **Settings**, choose **System**, and read the number shown under
    **Current version** in the **Updates** group.
  </Step>

  <Step title="What you were doing">
    The app you were dictating into, the file you uploaded, or the meeting you
    were recording, and what happened instead of what you expected.
  </Step>
</Steps>

If something failed silently, a screenshot of the error or the relevant part of
your logs helps. Logs live in `%APPDATA%\neato-echo\logs`. See
[Common problems](/troubleshooting) for how to turn on debug logging and
capture the problem.

## Where to go for what

| You want to                                   | Go here                                                                                     |
| --------------------------------------------- | ------------------------------------------------------------------------------------------- |
| Ask a question or report a problem            | [hello@neatoventures.com](mailto:hello@neatoventures.com)                                   |
| File a reproducible bug or a feature request  | [GitHub Issues](https://github.com/markhiltonapps/neato-echo/issues)                        |
| Report a security vulnerability               | [hello@neatoventures.com](mailto:hello@neatoventures.com), and please don't open a public issue |

You never have to open a GitHub issue to get help. It's there because Neato Echo
is open source and some people prefer it. Email is the front door.

## Privacy

Please don't paste passwords, API keys, or payment card details into a support
email. If we need something sensitive to help you, we'll tell you a safe way to
send it.
